### Projects

**[Where Istanbul's public transport falls short](https://github.com/yusufyucell/istanbul-mobilite-firsat-analizi)**
I used six months of Istanbul open data (around 870 million transit trips) to find the districts where commuters are worst served during work hours. Then I matched each district with the shared-mobility option that fits it, checked whether discount coupons would pay for themselves, and designed an A/B test to measure it.
